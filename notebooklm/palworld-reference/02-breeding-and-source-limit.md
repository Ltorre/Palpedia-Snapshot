# Breeding: source map and access limitation

## Sources

- https://palworld.wiki.gg/wiki/Breeding — requested wiki reference. Its public page was protected by a Cloudflare challenge from this environment, so this knowledge base does not reproduce, scrape, or invent its page text.
- https://palworld.gg/breeding-calculator — interactive calculator entry point.
- https://palworld.gg/breeding-path — interactive breeding-path entry point.

## Use in NotebookLM

For a specific breeding result or parent path, open the linked calculator/path tools and verify against the live page. Each Pal record in this bundle also includes its calculator-facing breeding rank, alongside identity, type, work, combat and drop data.

## Why this note is intentionally short

The wiki's robots policy exposes a reference-use signal and its page was not retrievable here without bypassing an access challenge. Keeping an explicit source note avoids treating unavailable text as factual content.
