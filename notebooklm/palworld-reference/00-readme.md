# Palworld NotebookLM reference corpus

This folder is the bundled, source-linked reference corpus for Palpedia Snapshot. Create a NotebookLM notebook in your own Google account, then upload every Markdown file in this folder plus the personal files from your latest Palpedia Snapshot export. See `../README.md` in this repository for the exact setup steps and prompts.

## Coverage

- 299 Pal records grouped into 15 files.
- Active, passive, and partner skills.
- Items, weapons, armor, structures, technology, capture tools, map, tier-list, and breeding reference notes.
- One Wiki-derived active-skill note.

## Scope and freshness

The corpus is a factual snapshot generated on 2026-08-08 from palworld.gg pages and the recorded Wiki source noted in the individual files. Values can change with game patches. It is deliberately compact, source-linked, and does not include a pre-created shared NotebookLM notebook.
