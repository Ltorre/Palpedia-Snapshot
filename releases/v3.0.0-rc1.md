# Palpedia Snapshot v3.0.0-rc1

This release candidate previews the in-app breeding planner and bundles the complete Palworld Markdown reference corpus. It keeps the application read-only while moving the full breeding-tree calculation into the Windows interface.

## Create your own NotebookLM notebook

The old shared NotebookLM template is retired. Create a private notebook in your own Google account at [NotebookLM](https://notebook.google.com/), then:

1. Download `palpedia-snapshot-notebooklm-reference.zip` from the release, unzip it, then upload all 31 Markdown files in `palworld-reference`.
2. Create a fresh Palpedia Snapshot export and upload every file from its `export_<date time>` folder except `world.json`.
3. For collection questions, cite `pals.csv` or `palpedia-progress.md` in your prompt. For breeding questions, include `breeding-rules.md`, `breeding-direct-pairs.csv`, and `breeding-candidates.md` so NotebookLM uses exact outcomes and your individual traits.

The bundled reference corpus and a complete personal export total 39 sources. When you make a new export, replace the old personal files in the notebook with the newest set. See `notebooklm/README.md` in the repository for prompts and the exact file list.

## Try the focused workspaces

1. Download `palpedia-snapshot-windows-amd64.exe` and open it normally.
2. The first screen shows only the save picker, language, and theme controls. Select a world or browse directly to its `Level.sav`.
3. Use **Change save** if necessary, then choose one workspace: **NotebookLM export**, **Breeding planner**, or **Quickest route**. The selection keeps the screen focused; the other two choices stay directly above it.
4. In **Breeding planner**, the app loads current party/Palbox Pals and shows when the collection and save were last updated. Search by a Pal’s player-facing name or passive trait, filter by sex, and sort by level. Identical species/sex/passive-trait combinations are reduced to their highest-level Pal. Once one parent is selected, the list automatically shows only Pals of the other sex.
5. Choose one real male and one real female Pal, then click **Calculate selected pair** for the exact child species. For example, `BOSS_GrassMammoth` is shown as **Mammorest**.
6. In **Quickest route**, choose the target in its outlined picker, then click **Find quickest breeding route**. The result is grouped into generation-aligned rows, so both parents stay on the same layer even when another branch is deeper. For any non-target Pal, choose **Avoid species** to remove it entirely, or **Breed new** to add that Pal’s own parent branch above the current route without replacing the rest of the tree. Use **Breed new** on a grandparent to add another earlier layer. Optionally start only from Pals with gold and/or diamond traits. **Use all Pals again** clears these decisions. Raw Character IDs such as `SheepBall` or `PinkCat` also work.
7. For routes longer than two breeding generations, use the listed Philanthropist and Babysitter Pals from your own collection to speed up the breeding farm.

When the target is already owned, the result says so and then computes the shortest route without using any owned copies of that target. This makes the route useful for breeding a fresh Pal with a different passive-trait inheritance goal.

The selected male and female parents stay visible in dedicated cards above the scrollable collection list, so selecting the second parent does not require moving through the page.

Use the **Light/Dark** switch in the header to choose the interface theme. The whole application canvas changes with the setting, including the background. Gold traits use yellow labels and diamond traits green labels. Standard traits are translated too: `CraftSpeed_up1` is **Serious**, `PAL_ALLAttack_up1` is **Brave**, and hovering a known trait shows its in-game effect.

The route gives the fewest sequential breeding generations from the loaded male/female collection. It uses the bundled special-combination, rank, and tie-break rules from v2.1.0.

## Important limits

- The planner works from current party and Palbox Pals only; base, wild, and unassigned Pals are not treated as owned parents.
- It calculates species routes. Passive inheritance and egg gender are still subject to the game’s RNG, so a later step may require hatching additional eggs to obtain the needed sex or trait combination.
- Gold and diamond filters use bundled rank-3 and rank-4 passive-trait catalogs. Unknown or future game traits remain visible by raw game ID and can still be searched.
- Refreshing and exporting read the save again but never change it.

## RC status

This is a v3.0.0 release candidate for local testing. It is intentionally published on the `v3.0.0-rc1` branch and is **not merged into `main`**. Please test it with a copied or backed-up save before relying on a breeding route after a Palworld game update.
