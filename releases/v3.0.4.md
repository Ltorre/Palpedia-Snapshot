# Palpedia Snapshot v3.0.4

v3.0.4 fixes an unstable quickest-route family tree. When several bred Pals shared the same parent position, the cards could change order during a redraw, especially while hovering a card. Tree ordering is now deterministic, so cards and their connecting lines stay in place while you inspect the route.

## Download and use

1. Download `palpedia-snapshot-windows-amd64.exe` from this release and open it normally.
2. Select a `Level.sav`, then choose **Quickest route**.
3. Inspect, hover, avoid, or breed new from cards in a multi-generation route without the displayed tree moving unexpectedly.

The app remains read-only: it never modifies the selected save or its directory, and makes no network requests at runtime.
