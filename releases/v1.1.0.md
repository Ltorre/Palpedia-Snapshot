# Palpedia Snapshot v1.1.0

This release adds personal exports for shared worlds.

## Choose the player

Use `--list-players` with a `Level.sav` to list the player UIDs, levels, and names found in the save. Then pass one UID to `--player`:

```powershell
.\palpedia-snapshot-windows-amd64.exe --level "D:\path\to\Level.sav" --list-players --oodle-lib "D:\path\to\oo2core_9_win64.dll"

.\palpedia-snapshot-windows-amd64.exe `
  --level "D:\path\to\Level.sav" `
  --output "D:\path\to\personal-export" `
  --player "player-uid-from-list" `
  --oodle-lib "D:\path\to\oo2core_9_win64.dll"
```

## NotebookLM benefit

With `--player`, `pals.csv`, `capture-history.csv`, and `collection.md` contain only the selected player's collection and capture history. This makes the CSV safe to add to that person's copy of the [Palworld Palpedia NotebookLM template](https://notebook.google.com/notebook/fec4f41d-1c32-4b8d-975c-a0fbe3f7eba1).

`world.json` intentionally remains the complete parsed world export for advanced local inspection.

## Safety

The tool continues to read save files only and writes output only to the selected directory outside the save folder.
