# Palpedia Snapshot v1.4.0

This release exports each owned Pal's passive traits and adds a breeding-oriented report.

## Passive traits in the CSV

`pals.csv` now includes a `passive_traits` column. It contains the passive-skill IDs stored directly in the game save, separated by semicolons when a Pal has multiple traits.

The IDs are retained exactly as stored rather than converted through an incomplete hard-coded label list. This lets NotebookLM interpret the latest effects using its Palworld passive-skills source material.

## Breeding candidates report

`breeding-candidates.md` groups all currently owned party and Palbox Pals by passive trait. Each candidate row includes:

- Pal Character ID
- gender
- level
- current storage
- all of that Pal's passive traits

Add it to the [Palworld Palpedia NotebookLM template](https://notebook.google.com/notebook/fec4f41d-1c32-4b8d-975c-a0fbe3f7eba1) with `pals.csv`. You can ask the notebook to find keepers and parent combinations for a target trait set.

## Safety

Passive traits are read from the save only. The tool does not alter Pals, traits, breeding settings, or any game file.
