# Palpedia Snapshot v2.0.0

Palpedia Snapshot v2.0.0 makes the save exporter usable without command-line arguments or a Palworld installation lookup. It is a read-only Windows application that turns a local `Level.sav` into dated collection snapshots for NotebookLM, Palpedia progress, and breeding planning.

![Palpedia Snapshot interface](../docs/gui-preview.svg)

## Download and use

1. Download `palpedia-snapshot-windows-amd64.exe` from this release and double-click it.
2. The app starts at the usual local-save location:

   ```text
   C:\Users\<WindowsUser>\AppData\Local\Pal\Saved\SaveGames
   ```

3. Select the desired world from the detected list. If it is elsewhere, use **Browse for Level.sav** and choose the world's `Level.sav` file.
4. Choose an **export parent folder**. The default is `Documents\Palpedia Snapshot Exports`; it is always outside the game save folder. The parent may be on another drive.
5. Click **Create NotebookLM export**. The app creates a new dated folder such as `export_08-09-2026 18-42`. Windows folder names cannot contain `:`, so `-` separates the hour and minute.
6. Click **Open export folder in Explorer**, then drag these files into the shared NotebookLM template:

   - `collection.md`
   - `pals.csv`
   - `capture-history.csv`
   - `palpedia-progress.md`
   - `breeding-candidates.md`
   - `collection-diff.md` when this export compares against an earlier snapshot

   Do **not** add `world.json` to NotebookLM. It is the complete technical export, intended for troubleshooting.

### Shared worlds and comparison

Open **Show optional advanced options** only when needed:

- Use **Find players in this save** to select one player in a shared world. Leave Player UID empty to export every player.
- Use **Choose previous export** to select an earlier `export_<date time>` folder. The new snapshot then contains `collection-diff.md`, covering current-collection changes and Paldeck capture gains.
- Set **Players directory** only if it is not next to the chosen `Level.sav`.

The app reads save files only. It never writes inside the selected game save directory and makes no network requests at runtime.

## Breaking changes from v1.x

This is a major release because the name, executable, export contract, and compressed-save handling have changed.

| v1.x | v2.0.0 | Why it changed |
| --- | --- | --- |
| `palworld-save-scrap` | **Palpedia Snapshot** | The application now creates useful dated collection snapshots rather than being a technical scraper. The repository is now `Ltorre/Palpedia-Snapshot`. |
| `palworld-save-scrap-windows-amd64.exe` | `palpedia-snapshot-windows-amd64.exe` | The public binary follows the new product name. |
| `--output` was the final, empty export directory; `--force` could overwrite it | `--output` is an export **parent**; every run creates a new `export_<date time>` child folder | Snapshots stay available for comparisons and cannot overwrite a previous collection by accident. `--force` is removed. |
| Optional `--oodle-lib` and GUI Oodle-DLL selection | No Oodle argument or DLL selection | Current `PlM` saves need Oodle decompression, but relying on a proprietary DLL in a user's game files was unreliable. The Windows binary now includes the open-source Ooz decoder. |
| Apache-2.0 project distribution | GPLv3 distribution | Embedding the GPLv3 Ooz decoder makes GPLv3 the correct license for the combined application. Your save files and generated exports remain your own data. |
| `Documents\Palworld Save Scrap Exports` | `Documents\Palpedia Snapshot Exports` | The default location now follows the renamed application. |

The current executable can still be used from a terminal when arguments are provided:

```powershell
.\palpedia-snapshot-windows-amd64.exe `
  --level "D:\path\to\Level.sav" `
  --output "D:\Palpedia Snapshots"
```

## What is included

- Modern Windows graphical interface, in English and French.
- Automatic local-save discovery and native file/folder pickers.
- One-click opening of the completed export folder.
- Timestamped snapshots and a previous-snapshot picker for comparisons.
- Player selection for shared worlds.
- Passive traits in `pals.csv` and `breeding-candidates.md` for breeding analysis.
- Embedded open-source decoder for modern compressed saves; no Steam path, game DLL, or command-line setup is needed.
