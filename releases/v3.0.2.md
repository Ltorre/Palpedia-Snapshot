# Palpedia Snapshot v3.0.2

v3.0.2 adds complete French documentation alongside the English README.

## Documentation languages

- [English README](../README.md)
- [README en français](../README.fr.md)

Each README starts with a clear link to the other language. Both describe the same export files, save location, graphical interface, breeding planner, quickest-route family tree, NotebookLM workflow, command-line usage, and read-only safety limits.

## Download and use

1. Download `palpedia-snapshot-windows-amd64.exe` from this release and open it normally.
2. Select a `Level.sav`. Steam local worlds are normally under `C:\Users\<WindowsUser>\AppData\Local\Pal\Saved\SaveGames\<SteamID>\<WorldID>\Level.sav`.
3. Choose **NotebookLM export**, **Breeding planner**, or **Quickest route**. The application is available in English and French.

The app remains read-only: it never modifies the selected save or its directory, and makes no network requests at runtime. The release includes the Windows executable and the 31-file NotebookLM reference corpus.
