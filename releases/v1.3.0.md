# Palpedia Snapshot v1.3.0

This release adds export-to-export collection comparison.

## Compare snapshots

Pass an earlier export directory with `--compare` while creating a new export:

```powershell
.\palpedia-snapshot-windows-amd64.exe `
  --level "D:\path\to\Level.sav" `
  --output "D:\path\to\new-export" `
  --compare "D:\path\to\previous-export" `
  --player "player-uid-from-list" `
  --oodle-lib "D:\path\to\oo2core_9_win64.dll"
```

The previous export must contain the tool-generated `pals.csv` and `capture-history.csv` files. No previous game save is opened.

## New report

The resulting `collection-diff.md` shows:

- Pals added to the selected player's party or Palbox.
- Pals no longer in that current collection.
- Paldeck capture-count gains by Character ID.
- Current and previous total/unique collection counts.

Add this file to your own [NotebookLM](https://notebook.google.com/) notebook alongside `pals.csv` and `palpedia-progress.md` to ask about recent progress and the most useful next captures.

## Safety

Comparison reads prior CSV exports only. The tool never writes to either the old or current game save.
