# Palpedia Snapshot v1.2.0

This release adds `palpedia-progress.md`, a concise personal progress source for NotebookLM.

## What the report contains

For each exported player, the report shows:

- Current unique species in party and Palbox.
- Paldeck capture-record species and total recorded captures.
- A table of currently owned species with the corresponding capture count.
- Species recorded as captured but not currently in the party or Palbox.

The data comes directly from the save. The report does not invent a total Palpedia size or declare any species missing without a versioned game catalogue.

## NotebookLM workflow

1. Create a notebook in [NotebookLM](https://notebook.google.com/) with your own Google account.
2. Export your selected player with `--player` when using a shared world.
3. Add both `pals.csv` and `palpedia-progress.md` to your notebook copy.
4. Ask which missing or no-longer-owned species are easiest to capture next.

## Safety

The report is generated from a read-only save parse. Game save files are never written or moved.
