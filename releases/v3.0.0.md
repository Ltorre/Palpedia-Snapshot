# Palpedia Snapshot v3.0.0

Palpedia Snapshot v3 turns the save exporter into a complete, read-only Palpedia and breeding companion for Windows. It includes the 31-source Palworld reference corpus, a focused graphical interface, an exact breeding calculator, and an interactive quickest-route planner.

![Quickest breeding route family tree](https://raw.githubusercontent.com/Ltorre/Palpedia-Snapshot/v3.0.0/docs/quickest-route-tree.svg)

## Download and use

1. Download `palpedia-snapshot-windows-amd64.exe` from this release and open it normally.
2. Select a `Level.sav`. Steam local worlds are normally at `C:\Users\<WindowsUser>\AppData\Local\Pal\Saved\SaveGames\<SteamID>\<WorldID>\Level.sav`.
3. Choose one workspace: **NotebookLM export**, **Breeding planner**, or **Quickest route**. Use **Change save** at any time to select another world.
4. For a NotebookLM export, choose a destination folder. The app creates a new timestamped `export_<date time>` subfolder, then offers to open it in Explorer. Add every file from that folder to your own NotebookLM notebook except `world.json`.

## Build your own NotebookLM notebook

The old shared notebook template is retired. Go to [NotebookLM](https://notebook.google.com/) with your own Google account:

1. Download and unzip `palpedia-snapshot-notebooklm-reference.zip` from this release.
2. Upload all 31 Markdown files inside `palworld-reference`.
3. Upload your latest personal export files, excluding `world.json`.
4. For breeding questions, include `breeding-rules.md`, `breeding-direct-pairs.csv`, and `breeding-candidates.md` alongside `pals.csv`.

The reference corpus plus a complete personal export uses 39 sources, leaving room under NotebookLM's 50-source limit. Replace personal export files when you make a newer snapshot.

## New in v3

- Focused English/French Windows interface with light and dark themes.
- Save-first workflow: choose a save, then open only the workspace you need.
- Breeding planner that searches by Palpedia name, game ID, or passive trait; filters sex; sorts level; and keeps selected parents visible.
- Exact child-species calculation using bundled Palworld.gg breeding rules, rather than a median approximation.
- Quickest breeding route with name suggestions, gold/diamond starter filters, species avoidance, and additive **Breed new** branches for passive-trait inheritance planning.
- Connected left-to-right family-tree visualization, so parents visibly merge into every child in a multi-step route.
- High-value breeding-farm helper detection for Philanthropist and Babysitter Pals in routes longer than two generations.
- Complete 31-file Palworld Markdown reference corpus bundled as a release asset for private NotebookLM notebooks.

## Limits and safety

- The app reads the selected save files only; it never changes, moves, or writes into the Palworld save folder.
- It makes no runtime network requests. Breeding rules, trait names, and the reference corpus are bundled with the release.
- Routes calculate Pal species. Passive inheritance and egg sex remain game RNG, so hatch extra eggs when a later step needs a particular sex or passive combination.
- The planner uses Pals currently in the selected player's party and Palbox. For shared worlds, select the player in the optional advanced controls.
- Modern compressed saves use the included open-source Ooz decoder. On first use, it writes a hash-checked helper into the Windows user cache and works on temporary data only.
