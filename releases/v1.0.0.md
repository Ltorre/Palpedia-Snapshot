# Palworld Save Scrap v1.0.0

First public release of a read-only Palworld save exporter for Windows x64.

## What it exports

Given a `Level.sav` and its matching player saves, the executable produces four files in an explicitly selected output directory:

- `collection.md`: player-level collection summary, party, and Palbox roster.
- `pals.csv`: every decoded Pal, including party, Palbox, base, and world entities.
- `capture-history.csv`: historical Paldeck capture counts for each player.
- `world.json`: the complete typed view of decoded players, Pals, guilds, bases, and parser diagnostics.

## How to run it

For a typical Steam installation, find the desired world's `Level.sav` here:

```text
C:\Users\<WindowsUser>\AppData\Local\Pal\Saved\SaveGames\<SteamID>\<WorldID>\Level.sav
```

Choose the `<WorldID>` folder that also contains the corresponding `Players` directory. The executable never searches or assumes this path; it always requires the selected `Level.sav` path.

```powershell
.\palworld-save-scrap-windows-amd64.exe `
  --level "D:\path\to\Level.sav" `
  --output "D:\path\to\export" `
  --oodle-lib "D:\path\to\oo2core_9_win64.dll"
```

`--output` is required and must be outside the save directory. The player `Players` directory is read from beside `Level.sav`, or can be supplied with `--players-dir`.

## Safety and compatibility

- The application reads save files only; it never writes, moves, backs up, or rewrites them.
- It makes no network request while running.
- Current Oodle-compressed (`PlM`) saves require an explicit path to the user’s own `oo2core_9_win64.dll`. The DLL is not included or downloaded.
- This release is Windows x64. Run `--version` to confirm the executable version.
