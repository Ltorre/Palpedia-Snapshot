# Palpedia Snapshot v3.0.3

v3.0.3 makes the breeding planner easier to scan: the Pal search, trait and sex filters, level sorting, and matching collection list now sit together in the same outlined card style as the quickest-route picker.

## Download and use

1. Download `palpedia-snapshot-windows-amd64.exe` from this release and open it normally.
2. Select a `Level.sav`, then choose **Breeding planner**.
3. Use the outlined **Search your Pals** area to find a Pal by name, game ID, or passive trait; filter by trait tier or sex; and sort by level.

The app remains read-only: it never modifies the selected save or its directory, and makes no network requests at runtime.
