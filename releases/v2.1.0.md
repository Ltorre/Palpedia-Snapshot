# Palpedia Snapshot v2.1.0

v2.1.0 adds exact breeding outcomes for the Pals currently stored in the selected player's party and Palbox. It fixes a common NotebookLM mistake: offspring species are not calculated from a median of Pal names, levels, ranks, or passive traits.

## Download and use

1. Download `palpedia-snapshot-windows-amd64.exe` from this release and double-click it.
2. Select a world, choose an export parent folder, then click **Create NotebookLM export**.
3. Click **Open export folder in Explorer** when the export completes.
4. Add every generated file except `world.json` to your copy of the [Palworld Palpedia NotebookLM template](https://notebook.google.com/notebook/fec4f41d-1c32-4b8d-975c-a0fbe3f7eba1).

The full NotebookLM file list is:

- `collection.md`
- `pals.csv`
- `capture-history.csv`
- `palpedia-progress.md`
- `breeding-candidates.md`
- `breeding-rules.md`
- `breeding-direct-pairs.csv`
- `collection-diff.md`, only when comparing to an earlier snapshot

Do **not** add `world.json`. It is a technical troubleshooting export, not a NotebookLM source.

## Exact breeding export

`breeding-direct-pairs.csv` contains one row for every possible male/female species pair you own. Each row includes the exact child Character ID, the rule type, both breeding ranks, and the calculated target rank. Pals with an unknown gender are not included because they cannot form a known valid breeding pair.

`breeding-rules.md` tells NotebookLM how to interpret this data:

- Special combinations override the generic calculation; two of them are gender-specific.
- Generic breeding uses `floor((parent A rank + parent B rank + 1) / 2)`, then selects the closest eligible Pal breeding rank. Equal distances use the game's priority tie-breaker.
- Identical species breed into themselves unless a special-combination rule applies.
- Passive traits affect which individual parents are desirable, but never the child species. Use `pals.csv` and `breeding-candidates.md` alongside the pair CSV to plan inheritance.

This release bundles a factual breeding-rule snapshot derived on 2026-08-09 from the public [Palworld.gg breeding calculator](https://palworld.gg/breeding-calculator). It makes no network request at runtime. A future Palworld update can change the rules, in which case use a newer Palpedia Snapshot release when available.

## Compatibility

This is a non-breaking minor update. Existing export folders remain valid and v2.1.0 continues to read saves exactly as v2.0.0 did. New snapshots simply include `breeding-rules.md` and `breeding-direct-pairs.csv`.

The application remains read-only: it never writes inside the selected game save directory.
