# Palpedia Snapshot v1.0.1

This release makes `pals.csv` a dedicated NotebookLM-ready collection source.

## Personal Palpedia CSV

`pals.csv` now includes only Pals currently owned by a player: Pals in that player's party or Palbox. It excludes wild entities, base workers, and other world characters, so it represents the collection that can help identify Palpedia gaps.

The complete parsed world remains available in `world.json` for advanced inspection.

## Use with the shared NotebookLM template

1. Duplicate the [Palworld Palpedia NotebookLM template](https://notebook.google.com/notebook/fec4f41d-1c32-4b8d-975c-a0fbe3f7eba1).
2. Run this executable against your own `Level.sav` and matching `Players` directory.
3. Add the generated `pals.csv` to your copy of the notebook.
4. Ask the notebook which Pal species are missing and which capture route is easiest.

## Safety

The application only reads game saves and writes exports to the selected directory outside the save folder. It does not modify the game files.
